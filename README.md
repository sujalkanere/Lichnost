# Lichnost

**личность** — the Russian word for *personality*.

Lichnost is a calm, beautiful self-reflection app: answer 25 honest questions and
receive a portrait of your personality across **five strands** — Openness,
Conscientiousness, Extraversion, Agreeableness, and Stability (a light, accessible
take on the Big Five model of personality research).

No account. No tracking. No server. **Your answers never leave your browser.**

---

## The story of this build

This repository originally contained no specification — no `SRS.md` exists in the
repo, on the linked URL, or in any branch or issue. So this app was thoughtfully
interpreted from the repo's name and built around one question:

> *What would a person use this for, who by, and why?*

The answer that shaped everything: **a curious person with ~4 spare minutes who
wants honest self-insight, in a format that feels like a gift rather than a
report.** Everything in the product serves that person. Features that didn't
survive that test were left out on purpose.

## What you can do

- **Take the questionnaire** — 25 statements, five per strand, interleaved so no
  two consecutive questions measure the same thing. Answer with a click or the
  `1`–`5` keys.
- **Leave and come back** — answers autosave in `localStorage`; the home screen
  invites you to *continue* exactly where you stopped.
- **Read your portrait** — an animated radar of your shape, five strand cards with
  prose written for your side of each spectrum (low / middle / high), strongest &
  quietest strands, and a closing note that frames it as weather, not verdict.
- **Keep your history** — every portrait is stored locally; reopen or delete any of
  them, retake the questionnaire months later and watch the shape move.
- **Copy a summary** — one tap produces a plain-text digest you can paste anywhere.

## How it works under the hood

- **Stack:** hand-written HTML, CSS, and a single dependency-free `app.js`
  (~1,500 lines total with prose). No framework, no build step, no runtime
  requests. Fonts are self-hosted variable woff2 files (Fraunces + Inter).
- **Scoring:** each strand has five statements, some reverse-scored. Each answer
  maps to 1–5; a strand's raw score (5–25) is scaled to 0–100. Scores are bucketed
  into low / mid / high at 38 and 67 — each bucket has its own honest narrative,
  because a low score on Stability should read as *sensitivity*, not failure.
- **Radar:** a hand-rolled SVG pentagon (~40 lines). A chart library was
  deliberately declined.
- **State:** two `localStorage` keys — `lichnost.qs.v1` (in-progress draft) and
  `lichnost.hist.v1` (last 12 portraits, stored as compact score maps).

## Design

Warm **paper** ground with blurred colour blooms and a subtle paper-grain overlay;
**ink** typography set in Fraunces (a soft old-style serif with a wonky soul) for
voice and Inter for UI; **clay** as the single action accent. Each of the five
strands owns a hue that threads through the radar, the trait cards, and the
history. Motion is choreographed and gentle — and fully disabled under
`prefers-reduced-motion`.

## Honesty notes

- Lichnost is a **mirror for self-reflection, not a clinical assessment**. The
  items are original, written for warmth and clarity rather than psychometric
  validation; the prose narratives are crafted, not generated by a scoring
  algorithm with pretensions.
- A *weather report, not a verdict*: personality drifts with seasons, and this
  portrait is true for today.

## Run it

No install needed — it's static:

```bash
# from this directory, e.g.
python3 -m http.server 8080
# then open http://localhost:8080
```

Or open `index.html` directly (all assets are local).

## Layout

```
index.html        the four screens (home · quiz · working · result)
styles.css        the design system and all styling
app.js            the whole application (state, scoring, rendering)
assets/fonts.css  @font-face declarations
assets/fonts/     self-hosted variable fonts (latin + cyrillic for ЛИЧНОСТЬ)
favicon.svg       five-strand constellation mark
```
